# FAO-56 ETo Interactive Calculator

An interactive, browser-based reference evapotranspiration calculator using the FAO-56 Penman–Monteith equation.

## Features
- Slider-based entry for maximum/minimum temperature, relative humidity, wind speed and solar radiation
- Editable date, latitude, elevation and wind sensor height
- Automatic conversion of wind speed to 2 m
- Displays ETo, net radiation, vapour pressure deficit and wind speed at 2 m
- Clear-sky radiation check and input validation
- Interactive reference-grass illustration and practical interpretation

## Use
Open `index.html` in a modern web browser. No server-side software or external libraries are required.

## Method note
This is an educational and preliminary assessment tool. Use quality-controlled weather observations and verify results against FAO-56 procedures before operational irrigation or design decisions.
